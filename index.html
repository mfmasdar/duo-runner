The green-screen effect uses MediaPipe Selfie Segmentation (classic JavaScript build, no ES module import). It processes your camera video in Safari without transmitting the camera feed to this website's server.

How to use

  • Host this file as index.html on GitHub Pages, using HTTPS.
  • Open the site in Safari on iPad, paste an embeddable YouTube video and tap Load YouTube video.
  • Tap Enable camera + green screen and approve the camera permission if Safari asks.
  • Use the sliders to place your live body over the video. Run, jump or gesture along with the video; v3 is a visual overlay, not motion-driven video playback.
  • If a YouTube video blocks embedding, choose another or use the local video option.
